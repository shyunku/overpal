바뀌는 것

  • 아이템 탭은 기본으로 내가 있는 거점 + 내 인벤토리. 거점 밖이면 내 인벤토리만(이미 구현)
  • 다른 거점을 골라 보면 그 거점 상자만 보이고, 위에 "거점 N 보는 중" 띠와 "현재로" 버튼이 뜸. 다른 거점끼리 합치지 않음
  • 내가 거점을 옮기면(자동 모드) 따라 바뀜. 다른 거점을 골라 둔 상태면 "현재로"를 누를 때까지 유지

그대로인 것

  • 합계/위치별, 검색, 레이아웃, 창 크기

안

  • A 드롭다운: 제목 아래 "편들 · 거점 3 ▾"를 누르면 목록. 공간을 안 먹음
  • B 칩 줄: 합계/위치별 아래 거점 칩 한 줄. 한 번에 보이지만 줄 하나만큼 목록이 줄거나 창이 커짐(시안은 창 높이 유지, 목록이 한 줄 줄어듦)
  • 거점 이름은 게임에서 이름을 못 가져오면 "거점 1~5"(PalDefender 순서). 목록에 거리·아이템 수를 같이 보여 줌

정할 것

  • A 드롭다운 / B 칩 줄
