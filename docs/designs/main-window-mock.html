크기
레일 아이콘, "내 것 / 도감" 탭, 레이아웃 버튼, 목록 항목을 직접 눌러도 바뀜. "실제 크기"는 QHD 화면에서 보이는 비율 그대로임.

바뀌는 것

  • "아이템 수량" 창 → 메인 창. 왼쪽에 세로 아이콘 레일(아이템 · 팰 · 구조물 · 장소)
  • 팰 · 구조물 · 장소 탭은 제목 아래 "내 것 / 도감" 탭으로 전환(아이템 탭의 "합계 / 위치별" 자리)
  • 목록에서 항목을 누르면 같은 창 안에서 상세로 바뀌고, 제목줄의 ‹ 로 돌아감
  • 창 폭은 레일만큼(약 16%) 넓어짐. 일반 레이아웃은 모든 탭·화면에서 높이가 같음
  • 메뉴 바의 아이템 버튼은 "메인 창" 버튼이 됨

그대로인 것

  • 아이템 탭: 합계/위치별, 검색(안 가진 것 빨간 0), 3가지 레이아웃(이름만 컴팩트 / 일반 / 와이드로 바뀌고 이 순서로 놓임, 기본은 일반)
  • 배경 블러, 25% 틴트, 폰트, 클릭 통과 규칙, 창 위치

데이터

  • 내 것: 팰 = 거점 일꾼·파티·팰 상자, 구조물 = 거점에 지은 건물과 제작 진행, 장소 = 거점·플레이어·근처 빠른 이동
  • 도감: palworld-helper 데이터(팰·구조물 전체, 빠른 이동·탑·던전·알파 팰)
  • 점선 표시(일꾼 상태, 제작 진행)는 서버에서 가져올 수 있는지 구현 전에 조사함

레이아웃 비교 ("다른 탭 레이아웃")

  • 일반만: 팰·구조물·장소는 항상 일반. 레이아웃 버튼은 아이템 탭에서만 보임. 다른 탭으로 가면 일반으로 보이고 아이템으로 돌아오면 원래 레이아웃
  • 3가지 모두: 모든 탭에 컴팩트 / 일반 / 와이드 버튼. 레이아웃은 탭마다 따로 기억
    • 컴팩트: 내 것 요약(일꾼 상태, 제작 진행, 가까운 장소). 도감은 컴팩트에서 안 보임
    • 와이드: 왼쪽 분류 + 격자

정할 것

  • 다른 탭 레이아웃: 일반만 / 3가지 모두
