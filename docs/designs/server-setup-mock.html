▣ 게임 서버
UE4SS와 PalDefender는 정해 둔 버전을 각 프로젝트의 공식 GitHub 릴리스에서 받아 서버 폴더에 넣습니다(MIT 라이선스). Overpal 모드는 서버를 켤 때 자동으로 넣습니다.

＋ 새 게임 서버 만들기

Steam의 서버 설치 도구(SteamCMD)로 팰월드 전용 서버를 받고, Overpal에 필요한 것까지 설치합니다.

서버 관리에 쓰입니다. 자동으로 만든 값을 그대로 써도 됩니다.
친구들이 서버에 들어올 때 입력하는 비밀번호입니다.
약 5~8GB를 받습니다. 몇 분 걸릴 수 있습니다.

바뀌는 것

  • 설정 › 게임 서버 폴더 아래에 폴더 상태 목록: 게임 서버, UE4SS, PalDefender, PalDefender REST, Overpal 모드
  • 빠진 것에는 '설치' 버튼, 아래에 '한 번에 설치'. 설치 중엔 진행 막대
  • '한 번에 설치'는 순서대로: UE4SS → PalDefender → REST 설정. 실패하면 그 단계에서 멈추고 다시 누르면 빠진 것부터
  • 화면 문구는 모두 존댓말, 줄임표는 '...'
  • '새 서버 만들기' 버튼 → 작은 창: 폴더·서버 이름·관리자 비밀번호·접속 비밀번호 입력 후 단계별 진행
  • 단계: SteamCMD 받기 → 서버 받기 → 처음 실행해 설정 파일 만들기 → 설정 채우기(이름·비밀번호·REST) → UE4SS → PalDefender(+REST·토큰) → Overpal 모드
  • 다 되면 그 폴더가 이 프로필의 게임 서버로 들어가고, 토스트로 알림. 포트포워딩은 안내 문구만
