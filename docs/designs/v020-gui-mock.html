바뀌는 것

  • 설정에 '게임 서버' 섹션이 새로 생김. 게임 서버 폴더를 앱 서버 섹션에서 이리로 옮김
  • 포트 5개를 한 곳에서 편집 (점선 영역). 앱 서버 포트도 여기로 옮김
  • 지금 값은 서버 폴더 설정 파일에서 읽어 옴
  • 게임 서버가 켜져 있으면 포트 칸이 잠김 (파일을 바꿔도 재시작 전엔 반영 안 됨)
  • 다른 Palworld 서버가 실행 중이면 겹치는 포트를 빨간 테두리로 경고 ('포트 겹침 경고' 버튼)

그대로인 것

  • 접속 허용 스위치, 클라이언트·오버레이 설정, 저장 바

정할 것

  • Steam 쿼리 포트(27015): 처음엔 4개라고 했는데, 두 서버를 같이 켜려면 이것도 달라야 함. 그래서 5칸으로 넣음. 빼도 됨
  • 게임 서버 폴더를 '게임 서버' 섹션으로 옮기는 것

바뀌는 것

  • 버튼 3개: 취소 / Overpal만 종료 / 저장 후 종료
  • 각 버튼이 하는 일을 본문에 한 줄씩 설명함
  • Overpal만 종료하면 서버는 계속 돌고, 다음에 Overpal을 켜면 실행 중으로 표시됨 (지금도 프로세스로 찾고 있어서 그대로 됨)

그대로인 것

  • 저장 후 종료 동작 (저장 → 서버 종료 대기 → 앱 종료), 관리 API가 꺼진 경우의 안내

바뀌는 것

  • 부족하지만 바로 아래 재료가 전부 '완료'인 줄: 기본으로 접힘
  • 그 줄의 글자: 빨간 "N 부족" → 노란 "N 제작 가능"

그대로인 것

  • 완료 줄(초록·접힘), 진짜 부족한 줄(빨강·펼침), 링 색, 손으로 펼치기/접기
