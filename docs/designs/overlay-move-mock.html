메인 창 위치

'Esc(상호작용)'에서 메인 창 윗부분(제목 줄)이나 메뉴 바 맨 왼쪽 손잡이를 끌어 보셈. 메인 창 테두리·모서리를 끌면 크기가 바뀜. 메인 창은 화면 가운데(점선)를 넘으면 메뉴 탭이 그쪽으로 옮겨감.

바뀌는 것

  • 메인 창 메뉴 탭 위치: 창의 가운데가 화면 왼쪽 절반에 있으면 메뉴 탭(아이템/팰/구조물/장소)이 창 왼쪽, 오른쪽 절반이면 창 오른쪽. 탭의 주황 막대도 바깥쪽으로 감
  • 같이 바뀌는 것: 오른쪽 절반에 두면 창이 화면 오른쪽 기준으로 붙음. 그래서 컴팩트/일반/와이드로 폭이 바뀌면 왼쪽으로 늘어나고, 오른쪽 끝은 그대로 있음 (지금은 늘 왼쪽 기준이라 오른쪽으로 늘어남)
  • Esc 등 상호작용 상태: 편집 모드를 켜지 않아도 메인 창 윗부분(제목 줄: 제목·거점·모드 버튼 줄)을 끌어 옮길 수 있음. 마우스를 올리면 살짝 밝아지고 손 모양 커서. 그 줄의 버튼(모드, 거점 고르기)은 원래대로 눌림
  • 메뉴 바: 맨 왼쪽에 점 6개 손잡이. 상호작용 상태에서 이걸 끌면 메뉴 바가 움직임. 플레이 중엔 흐리게만 보임
  • 옮긴 위치는 지금처럼 저장됨
  • 메인 창 크기 조절 (새로 추가): 상호작용 상태에서 메인 창 테두리·모서리를 끌어 폭과 높이를 바꿈. 탭 반대쪽 아래 모서리에 작은 빗금 표시. 컴팩트/일반/와이드마다 크기를 따로 기억함. 최소 크기는 제목 줄과 목록 몇 줄이 안 깨지는 선(일반 기준 지금 폭의 약 80%, 높이 절반쯤), 최대는 화면 안. 내용이 넘치면 목록만 스크롤

그대로인 것

  • 플레이 중(상호작용 아님)엔 아무것도 안 끌림, 클릭도 게임으로 통과
  • 설정의 '편집' 모드: 지금처럼 모든 창(미니맵 포함)을 어디든 잡고 옮김
  • 미니맵, 설정 창은 손잡이 없음(편집 모드로만 옮김)
  • 목록, 탭 버튼 등 나머지 부분은 끌리지 않음

정한 것

  • 메뉴 바 손잡이는 플레이 중에도 흐리게 보임
  • 끌 때 화면 테두리·다른 창과 15px 간격으로 달라붙음(±15px 안), 끄는 도중에 (시안엔 없음, 앱에 구현됨)
