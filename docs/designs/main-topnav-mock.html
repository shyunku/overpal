좁을 때 아이콘에 마우스 올리면 이름 툴팁 나옴 (지금 레일과 같음).

거점 1 · 보관함 14개
아이템 검색

바뀌는 것

  • 왼쪽(또는 오른쪽) 세로 아이콘 레일 → 창 맨 위 가로 탭바
  • 탭 5개가 탭바 폭을 똑같이 나눠 가짐
  • 창 폭 460px 미만: 아이콘만, 마우스 올리면 이름 툴팁
  • 창 폭 460px 이상: 아이콘 + 이름, 세로 가운데 정렬
  • 레일 56px가 빠지니 내용 폭이 그만큼 넓어짐 (창 크기 자체는 그대로)
  • 화면 오른쪽에 둘 때 레일을 오른쪽으로 옮기던 동작(rail-right)은 필요 없어져서 없앰

그대로인 것

  • 탭 종류/순서, 아이콘, 제목줄(뒤로·레이아웃 버튼), 검색, 목록
  • 창 이동 손잡이는 지금처럼 제목줄 (탭바는 클릭만)
  • 레이아웃별 저장된 창 크기

정할 것

  • C(주황 밑줄 + 아래에서 올라오는 주황 그라데이션, 아이콘 주황) vs C2(같은 구성, 더 은은하게)
  • 이름 나오는 기준 폭 (460px 제안 — 와이드에서만 이름, 컴팩트·일반은 아이콘만. 드래그로 넓히면 이름 나옴)
