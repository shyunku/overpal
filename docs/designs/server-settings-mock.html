바뀌는 것

  • 게임 서버 탭에 '서버 설정': 서버 폴더의 PalWorldSettings.ini를 읽어 보여 주고, 저장하면 그 파일에 씁니다.
  • 자주 쓰는 것 30개 정도를 한국어 이름·설명과 함께 묶어서(서버 / 게임 배율 / 전투·생존 / 규칙 / 길드·거점) 보여 줍니다.
  • 나머지는 '고급' 칸에 접어 두고, 펼치면 원래 키 이름 그대로 검색해서 바꿀 수 있습니다. 목록은 서버의 DefaultPalWorldSettings.ini에서 읽어 게임 업데이트로 늘어난 항목도 나옵니다.
  • 기본값과 다른 항목은 왼쪽에 주황 줄. 바꾼 게 있으면 아래 저장 막대가 뜹니다.
  • 모든 항목 이름 옆에 ⓘ: 마우스를 올리면 설명, 원래 키 이름, 기본값이 뜹니다. 이름이 길면 말줄임표로 자릅니다.
  • 숫자는 1.000000 대신 1처럼 짧게 보이고, 저장할 때는 원래 형식으로 씁니다.
  • 숫자 칸은 좁게, 서버 이름·비밀번호·URL·목록처럼 긴 값은 한 줄 전체를 씁니다(고급 칸에서는 맨 아래로 모음).
  • 서버가 켜져 있으면 전부 잠기고 "끈 뒤 바꿀 수 있습니다" 안내.
  • 월드 폴더에 WorldOption.sav가 있으면 게임 규칙이 ini 대신 그 파일을 따른다는 경고.
  • 포트·관리 API(REST)는 여기서 빼고 설정 탭에서만 바꿉니다(Overpal 연결이 끊기지 않게).
  • #32(서버 이름 설정)는 이걸로 처리됩니다.

  • 설정 탭(폴더·포트·부품 목록)
