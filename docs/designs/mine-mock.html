일꾼 상태
실제 서버 데이터(2026-10-12)로 그렸음. 친구 이름만 바꿨음. 창은 게임 속 크기의 1.6배. 목록 항목을 눌러도 상세로 감.

팰 (내 것)

  • 일반: 지금 있는 거점의 일꾼 → 파티 → 팰 상자 순. 거점은 아이템 탭처럼 제목 아래 드롭다운으로 바꿈
  • 줄: 아이콘 · 윗줄 이름(별명 우선)과 Lv · 아랫줄 종류와 공복 막대(색은 항상 주황). 아픔·부상·SAN 30 미만이면 이름 옆 빨간 표시
  • 컴팩트: 손이 가야 할 일꾼만(아픔·SAN 낮음·배고픔). 없으면 "일꾼 모두 정상"
  • 와이드: 왼쪽 거점·파티·팰 상자 + 카드(오른쪽 위 Lv, 문제 있으면 왼쪽 위 빨간 점)
  • 상세: HP 숫자, 공복 막대(오른쪽 고정 폭), SAN 숫자, 건강(아픔·부상), 작업 적성(도감)
  • 팰 상자는 400마리라 일반에선 상위 30만 보이고 "더 보기"(검색하면 전체에서 찾음)

구조물 (내 것)

  • 일반: 맨 위 "제작" 섹션(만드는 것 · (만든 수/요청 수) · 건물 이름 · 지금 하나 진행률 · 주황 막대) → 분류별 건물(오른쪽 ×개수)
  • 컴팩트: 제작 중인 것만
  • 와이드: 왼쪽 분류 + 카드(×개수, 제작 중이면 진행 막대)
  • 상세: 건물 이름(붙인 이름 포함), 개수, 제작 정보

장소 (내 것)

  • 일반: 거점 5곳(거리·일꾼 수·건물 수), 플레이어(접속 여부·거리), 가까운 빠른 이동 5곳
  • 컴팩트: 가장 가까운 거점·빠른 이동·접속 중인 친구
  • 상세: 거점 요약(일꾼·상자·제작 중) / 좌표
