표시 (비교용으로 켜고 끄기)
거점·내 위치·친구 3 위치는 실제 서버 데이터(2026-10-12). 친구 1·2는 지금 멀리 있어서 가장자리에 방향과 거리로 보임. 내 방향은 예시로 북동쪽. 아이콘 비교하려고 내 위치만 거점에서 조금 옮겼음.

바뀌는 것

  • 확대/축소: 숫자줄 -/=, 키패드 -/+. 배율은 ×0.1 · ×0.25 · ×0.5 · ×0.75 · ×1 · ×1.5 · ×2 (기본 ×1, 지금과 같음). ×0.5보다 멀면 마커를 작게, ×0.25 이하는 빠른 이동·탑만. 앱을 껐다 켜도 유지
  • 바꿀 때 아래쪽에 ×1.5 같은 배율이 1초 뜨고 사라짐
  • 게임이 앞에 있을 때만 키를 받음. 키를 가로채지 않아서 게임에도 그대로 전달됨
  • 거점 범위(점선 원), 화면 밖 친구(가장자리 화살표 + "닉네임 (2.5km)"), 지도 마커 3종(빠른 이동·탑·알파 팰)
  • 내 방향: 내 위치 아이콘이 이동 방향으로 돎. 서버가 보는 방향을 안 줘서 움직인 방향으로 추정(0.5초마다 위치). 서 있거나 제자리에서 돌기만 하면 마지막 방향 유지
  • 거점·내 위치 아이콘 교체 (위 후보)

빠지는 것

  • 미니맵 안 친구 이름, 던전
  • 지도 마커는 지금 가진 데이터(paldb)의 4종이 전부임. 게임 지도에 나오는 다른 표시는 데이터가 없음

그대로인 것

  • 미니맵 크기·위치·모양, 내가 가운데, 북쪽이 위, 마우스 클릭 안 받음

정할 것

  • 거점 아이콘 A/B/C, 내 위치 아이콘 A/B/C
