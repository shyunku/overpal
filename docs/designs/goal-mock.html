바뀌는 것

  • 메인 창에 목표 탭 추가 (장소 다음, 깃발 아이콘)
  • 목표 목록: 아이템 아이콘·이름·목표 수량, 재료 충족 막대(모든 재료 보유/필요 비율), "지금 n개 만들 수 있음". 다 모이면 초록
  • 목표 상세: 수량 조절(- / + 와 직접 입력), 만드는 곳(제작대), 재료별 보유 / 필요와 부족분(빨강). 다 채운 재료는 완료(초록)
  • 재료 펼치기: 만들 수 있는 재료는 그 재료의 재료를 아래에 보여 줌. 하위 재료 수량은 부족한 만큼만 계산 (예: 금속 주괴 12개 부족 → 금속 광석 24개 필요)
  • 기본 접힘/펼침: 부족한 재료는 펼쳐져 있고, 다 채운 재료는 접혀 있음. ▸/▾ 로 자유롭게 접고 펼 수 있음. 그 재료가 다 채워지거나 다시 부족해지면 기본 상태(채움 → 접힘, 부족 → 펼침)로 돌아감
  • 겹치는 재료: 같은 재료가 여러 줄에 나오면 보유량을 위 줄부터 채움 (예: 쇠뇌 ×2 — 위의 '금속 주괴 20'이 보유 18을 먼저 쓰고, 아래 '못 → 금속 주괴 4'는 남은 0개에서 시작)
  • 목표 추가: 아이템 탭·구조물 탭(내 것/도감)에서 우클릭 → '목표로 설정'. 누르면 목표에 1개로 들어가고 목표 탭에서 수량 조절. 목록의 '+ 추가'(검색)도 그대로 둠
  • 보유량 = 선택한 거점 + 내 인벤토리 (아이템 탭과 같은 기준, 거점 메뉴로 다른 거점 고르면 그 거점으로). 실시간으로 바뀜
  • 목표는 이 PC에 저장되어 앱을 껐다 켜도 남음. 순서는 추가한 순서
  • 컴팩트 모드: 목표별로 부족한 재료만 한 줄씩

그대로인 것

  • 다른 탭, 창 크기·이동·마그넷, 거점 메뉴 동작

정할 것

  • 한 번 제작할 때 나오는 개수: 지금 가진 레시피 데이터에는 재료만 있고 결과 개수가 없음. 시안은 1개로 계산. 화살·탄약처럼 한 번에 여러 개 나오는 건 틀릴 수 있어서, 게임 데이터에서 결과 개수를 따로 찾아 넣을 예정
  • 목표 다 모였을 때: 그대로 두기(지금 시안) / 자동 완료 표시 / 알림
