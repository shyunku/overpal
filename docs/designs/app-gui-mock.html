흐름: ① 프로필 창 → 저장된 프로필(시작 모드 있음) → ③ Home / New Profile 또는 '매번 선택' → ② 모드 선택 → ③ Home
실제 기본 창 크기(912×702). 오른쪽 아래 모서리를 끌면 크기 조절됨(최소 760×540). 이름·주소는 예시. '시작 화면'에서 모드 카드, 나머지는 왼쪽 메뉴도 눌러 볼 수 있음.

바뀌는 것

  • exe 켜면 먼저 작은 프로필 창(460px)이 뜸. 드롭다운에서 프로필을 고르고 '시작하기'. 기본값은 New Profile(이름만 입력)
  • 저장된 프로필을 고르면 시작 모드·서버·마지막 사용이 요약으로 보임. 프로필 설정 수정은 Home의 설정 메뉴에서 하고, 거기서 저장하면 그 프로필에 저장됨
  • 프로필 = 설정 묶음 + 시작 모드. 시작 모드를 정해 두면 '열기'로 바로 Home, '매번 선택'이면 모드 선택 화면을 거침. 예: 실제 서버(둘 다), 테스트 서버(매번 선택), 친구 서버 접속(오버레이)
  • 모드 선택 화면: 큰 카드 3개(서버 / 오버레이 / 둘 다), 지난번 모드가 미리 골라져 있음. 시작한 뒤엔 모드를 못 바꿈. 바꾸려면 앱을 다시 켜야 함
  • cmd 창 없음. 창 닫으면 앱(오버레이·앱 서버) 종료
  • 창 기본 912×702, 크기 조절 가능(최소 760×540). 마지막 크기를 기억함
  • 아래 상태줄(모든 메뉴): 앱 서버, 게임 서버(PalDefender) 연결 상태와 지금 모드
  • 상태: 모드 상태, 서버 지연, 오버레이, 접속 중 플레이어, 친구 앱 접속, 최근 경고
  • 설정: 지금 모드에 맞는 칸만 보임(모드는 보기만). 저장 누르면 같은 모드로 앱이 다시 켜짐
  • 친구(server·both만): 추가하면 토큰 만들고 친구용 폴더(exe + 설정) 생성. 폴더 열기, 토큰 다시 만들기(이전 토큰 끊김), 삭제
  • 로그: 서버 멈춤 경고, 연결 오류, 친구 접속 기록. 지금 cmd에 찍히던 것
  • 처음 실행(프로필 없음)이면 드롭다운에 New Profile만 있음
  • 게임 서버 메뉴(홈 다음, 서버가 있는 모드만): 맨 위 카드에 상태(켜짐/켜는 중/끄는 중/꺼짐)·실행 시간·접속 인원과 켜기/끄기 버튼. 끄기는 확인 창을 거쳐 월드를 저장한 뒤 정상 종료(관리 API, 비밀번호는 서버 설정 파일에서 읽음). 켜기는 그 폴더의 PalServer.exe를 따로 띄움. PalHelper를 꺼도 게임 서버는 계속 돎. 아래 상태줄도 꺼짐/켜는 중/끄는 중을 보여줌. 그 아래 서버 정보(폴더·서버 이름·버전·실행 시간·접속·FPS)와 서버 로그(PalDefender 로그 / 모드 UE4SS 로그 전환, 새 줄이 생기면 따라 내려감)
  • 게임 서버 폴더 자동 찾기(설정, 서버가 있는 모드만): 버튼을 누르면 스팀 라이브러리(여러 개면 전부)의 steamapps\common\PalServer를 찾아 후보로 보여줌. 후보마다 모드·PalDefender 확인 여부. 누르면 그 폴더로 채워짐. 스팀 밖에 둔 서버는 '찾아보기'로 고름
  • 프로필은 시작할 때만 고름. Home에서는 프로필 창이 다시 뜨지 않고 프로필을 바꿀 수 없음(바꾸려면 앱을 다시 실행). Home의 설정 메뉴는 고른 프로필의 설정을 고침
  • 화면 문구는 존댓말(제품 문구). 이 옆 설명만 반말
  • 토큰은 가려서 보여주고 복사 버튼만 둠

그대로인 것

  • 게임 위 오버레이(메뉴바·메인 창·미니맵·설정), 앱 서버 기능
  • 프로필은 exe 옆 profiles\이름.json에 하나씩 저장(지금 설정 파일과 같은 형식 + 이름·시작 모드)

정할 것

  • 디자인 톤
  • 프로필 창을 매번 띄울지, '마지막 프로필로 바로 열기' 옵션을 둘지(지금 시안은 매번 띄움)
  • '친구 앱 접속'은 토큰별 마지막 요청 시각으로 판단(접속 끊김 즉시 감지 아님)
  • 친구 폴더를 어디에 만들지(기본: exe 옆 friends\이름)
  • client 모드에서 닉네임은 직접 입력 / 서버의 플레이어 목록에서 고르기
