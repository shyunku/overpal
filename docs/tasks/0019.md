## 기록

- 2026-10-12: 시안 확정. 결정 사항:
  - 팰·구조물·장소 탭은 "내 것 / 도감"을 제목 아래 탭으로 전환한다.
  - 레이아웃 이름과 순서는 컴팩트 / 일반 / 와이드이고 기본은 일반이다(기존 HUD / 사이드 / 전체). 모든 탭이 3가지를 쓰고 탭마다 따로 기억한다.
  - 상세는 같은 창 안에서 바뀐다. 제목줄의 ‹로 돌아간다.
- 2026-10-12 PalDefender 확인:
  - `/pals/<PlayerUID>`는 플레이어가 접속 중일 때만 된다(오프라인이면 404 `PLAYER_NOT_FOUND`).
  - `/guild/<id>`의 거점(`camps[]`)에 `pals`가 있다(테스트 거점은 비어 있음). `buildings`는 `"WIP"`이다.
  - 일꾼 상태(작업 중·휴식·SAN)와 제작 진행은 PalDefender에 없다. 모드로 읽어야 한다.
- 2026-10-12 13:20 19.2: `scripts/build_dex.py`로 palworld-helper에서 팰 299, 구조물 496, 지도 마커 4종(빠른 이동·탑·던전·알파 팰)을 가져온다.
  - 데이터 `app/public/data/dex.json` 445 KB. 메인 창만 `loadDex()`로 받아 와서 다른 오버레이 창은 불러오지 않는다.
  - 아이콘 815개를 96px로 줄여 `app/public/icons/dex/`에 둔다(2.5 MB). 원본이 없는 아이콘 1개(`T_icon_buildObject_FastTravelPoint`).
  - 팰 드롭과 구조물 재료의 아이템은 아이콘 파일, 한글 이름 순으로 게임 아이템 ID에 맞췄다(맞추지 못한 것 0).
- 2026-10-12 13:25 19.1, 19.3 화면 확인(게임 없이 `restart-app.ps1 -AlwaysShow`로 띄우고 layout.json으로 탭·레이아웃을 바꿔 캡처):
  - 일반 레이아웃은 아이템·팰·구조물·장소, 목록·상세 모두 창 높이 362px(QHD)로 같다. 와이드 614x400, 컴팩트 195x139.
  - 도감 목록(팰 3열 격자, 구조물 분류별 목록, 장소 레이어별 목록), 와이드(왼쪽 분류 + 격자), 상세(팰·구조물·장소)가 시안대로 보인다.
  - "내 것 / 도감" 선택은 탭별로 layout.json에 저장한다(`subs`).
  - 남은 확인(사용자): 레일·레이아웃 버튼·"내 것 / 도감" 클릭, 목록 항목 클릭 → 상세 → ‹, 도감 검색 입력.
- 2026-10-12 19:16 19.5 시안(`docs/designs/mine-mock.html`, 실제 서버 데이터로 생성) 결정 사항:
  - 팰 목록 줄: 윗줄 이름(별명 우선)과 Lv, 아랫줄 종류와 공복 막대(주황 고정, 안에 `현재 /최대`). 아픔·부상·SAN 30 미만일 때만 이름 옆에 빨간 표시.
  - 팰 상세: HP 숫자(PalDefender에 최대 HP가 없어 막대 없음), 공복 막대(오른쪽 고정 폭), SAN `n/100`, 건강(아픔·부상), 작업 적성.
  - 팰 상자는 목록에 일부만 보이고 "더 보기"로 펼친다. 검색은 전체에서 찾는다.
  - 제작은 `(만든 수/요청 수)`, 건물 이름, 지금 하나 진행률, 주황 막대(만든 수 ÷ 요청 수). 장소 상세의 제작 중도 같은 세로 리스트다.
  - 컴팩트: 팰은 손이 가야 할 일꾼(아픔·부상·SAN 30 미만·공복 25% 미만), 구조물은 제작 중인 것, 장소는 가까운 거점·빠른 이동·접속한 친구.
