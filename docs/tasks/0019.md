## 기록

- 2026-10-12: 시안 확정. 결정 사항:
  - 팰·구조물·장소 탭은 "내 것 / 도감"을 제목 아래 탭으로 전환한다.
  - 레이아웃 이름과 순서는 컴팩트 / 일반 / 와이드이고 기본은 일반이다(기존 HUD / 사이드 / 전체). 모든 탭이 3가지를 쓰고 탭마다 따로 기억한다.
  - 상세는 같은 창 안에서 바뀐다. 제목줄의 ‹로 돌아간다.
- 2026-10-12 PalDefender 확인:
  - `/pals/<PlayerUID>`는 플레이어가 접속 중일 때만 된다(오프라인이면 404 `PLAYER_NOT_FOUND`).
  - `/guild/<id>`의 거점(`camps[]`)에 `pals`가 있다(테스트 거점은 비어 있음). `buildings`는 `"WIP"`이다.
  - 일꾼 상태(작업 중·휴식·SAN)와 제작 진행은 PalDefender에 없다. 모드로 읽어야 한다.
- 2026-10-12 13:20 19.2: `scripts/build_dex.py`로 palworld-helper에서 팰 299, 구조물 496, 지도 마커 4종(빠른 이동·탑·던전·알파 팰)을 가져온다.
  - 데이터 `app/public/data/dex.json` 445 KB. 메인 창만 `loadDex()`로 받아 와서 다른 오버레이 창은 불러오지 않는다.
  - 아이콘 815개를 96px로 줄여 `app/public/icons/dex/`에 둔다(2.5 MB). 원본이 없는 아이콘 1개(`T_icon_buildObject_FastTravelPoint`).
  - 팰 드롭과 구조물 재료의 아이템은 아이콘 파일, 한글 이름 순으로 게임 아이템 ID에 맞췄다(맞추지 못한 것 0).
