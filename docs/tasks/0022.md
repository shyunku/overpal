## 기록

- 2026-10-13 13:01 시안 확정. 결정 사항:
  - 흐름: 프로필 창 → (시작 모드가 '매번 선택'이거나 New Profile이면 모드 선택) → Home. 프로필 창은 매번 뜨고 기본값은 New Profile.
  - 프로필 = 설정 + 시작 모드(서버 / 오버레이 / 서버+오버레이 / 매번 선택). 프로필 수정은 Home의 설정에서 하고, 저장하면 같은 프로필로 다시 시작한다.
  - Home 메뉴: 홈 / 로그 / 친구 / 설정(client 모드는 친구 없음). 앱 서버·게임 서버 연결 상태는 하단 상태줄에 고정.
  - 창: 기본 912×702, 크기 조절(최소 760×540). 창을 닫으면 앱이 끝난다. cmd 창 없음.
  - 프로필과 친구 폴더는 AppData(`%APPDATA%\com.palworldhelper.mod\`)에 둔다.
  - 친구 앱 접속 여부는 토큰별 마지막 요청 시각(30초)으로 판단한다.
  - 닉네임은 서버 플레이어 목록에서 고르고, 목록이 없으면 직접 입력한다.
  - 화면 문구는 존댓말 제품 문구.
- 2026-10-13 13:19 구현. 앱이 프로필 창 → (모드 선택) → Home으로 시작하고, 콘솔 대신 앱 로그(Home 로그, `%APPDATA%\com.palworldhelper.mod\logs\날짜.log`)를 쓴다. 앱 서버에 호스트 전용 `/api/host-status`(PalDefender 연결, 최근 10분 서버 지연, 친구 토큰별 마지막 요청)를 추가하고, 친구 토큰은 실행 중에도 바꿀 수 있다. 설정 파일(`--config`, `PALHELPER_CONFIG`, exe 옆 파일)로 켜면 프로필 창 없이 Home이 뜬다.
  - 고친 것: 시작할 때 세션 잠금을 잡은 채 오버레이 창을 만들어, Home 창의 요청과 교착되던 문제.
  - 2026-10-13 17:16 사용자 확인으로 완료(22.6).
- 2026-10-13 13:58 '시작하기'에서 Home이 빈 창으로 멈추던 문제를 고쳤다. 창을 만드는 명령(launcher_open, session_start)이 동기 명령이라 메인 스레드에서 창을 만들다 멈췄다. 비동기 명령으로 바꿨다. 앱 창은 자체 상단바를 쓰고(윈도우 프레임 없음), 앱 아이콘을 넣었다.
